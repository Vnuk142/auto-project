# Схема базы

Для первого запуска используется `Base.metadata.create_all()` при старте приложения.
Это создаёт таблицы `users` и `purchases` вместе с уникальным индексом активной
покупки. `create_all()` **не изменяет** существующие таблицы при обновлении модели.
Для следующих релизов с изменением схемы требуется переход на Alembic и резервное
копирование базы перед изменениями. Пользовательские данные сохраняются в томе
Docker `postgres_data`.
